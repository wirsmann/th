Profiles

A profile stores every setting except your key and your limits.

Tease mode (simulated remote)

Acts like someone else is running it: it builds up over a random time, holds, then backs off, then repeats with new random numbers each cycle. Your speed slider is the maximum, and the low and peak values below are percentages of it. While it's on, it replaces the ramp and pattern. The stroke range, speed cap, end slowdown, and time limits still apply. While a tease session is running, stopping or pausing counts as failing it: the device still stops right away, but you're locked out as if the time had run out.

Picking one fills in the tease settings below and turns tease mode on. You can still adjust any value afterward.

Limits

While a cooldown or the daily limit is active, Start is disabled and the limit boxes are locked. By default a failed session only counts the time you actually ran, plus the lockout. This lives in your browser, so clearing site data or using another browser bypasses it.
